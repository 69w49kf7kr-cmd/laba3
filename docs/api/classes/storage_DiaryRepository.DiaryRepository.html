    Class DiaryRepository

    Репозиторий дневника: читает и пишет diary.json в личной папке плагина (context.globalStorageUri). Папка общая для всех окон VS Code.

    Как избежать потери данных при нескольких открытых окнах: перед каждой записью файл перечитывается, и в свежую версию добавляются только новые сегменты этого окна. Пересечения времени устраняет Diary.addSegment через слияние интервалов.

    Все операции записи выстроены в очередь (цепочку промисов), поэтому две записи из одного окна никогда не идут одновременно.
