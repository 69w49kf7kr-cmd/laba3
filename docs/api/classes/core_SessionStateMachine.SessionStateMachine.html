    Class SessionStateMachine

    Автомат учёта времени.

               heartbeat                 тишина > таймаута / потеря фокуса
      idle ─────────────────► active ───────────────────────────────► idle
       ▲  ◄───── resume ────┐   │ ▲
       │                    │   │ │ heartbeat в другом файле:
       └─── pause ─────► paused │ └─ закрыть сегмент, открыть новый
                            ▲   │
                            └───┘ pause

    Каждое действие пользователя (печать, перемещение курсора, прокрутка, сохранение) — это «heartbeat». Пока heartbeat-ы приходят чаще, чем раз в idleTimeoutMs, сегмент продолжается. Когда наступает тишина, сегмент закрывается в момент последнего действия, и простой не засчитывается.

    Класс не знает про VS Code: события передаёт ActivityTracker, а время передаётся явно. Поэтому автомат легко покрыть тестами.
